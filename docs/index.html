A self-hosted alternative to commercial hosting panels

MassPanel is built for operators comparing an open-source cPanel alternative, DirectAdmin alternative, Plesk alternative or CyberPanel alternative. It is an independent project rather than a clone, and its capabilities and workflow should be evaluated using the public demo.

Web hosting
Nginx, PHP, MariaDB, certificates, redirects and backups.
DNS
BIND authoritative DNS with optional Cloudflare synchronization.
Email and groupware
Gromox, grommunio Web, EWS, ActiveSync, Rspamd and quarantine.
Customer management
Packages, limits, domains, support tickets and audit activity.

Install on Ubuntu 24.04 LTS

Start with a clean server, prepare the panel and mail DNS records, download a signed release and run sudo ./setup.sh. MassPanel is a public beta, so use a test server and keep independent backups.
