# Privacy information for operators

MassPanel is self-hosted software. The operator of each installation controls the customer accounts, websites, DNS records, support tickets, logs, mailbox metadata and integration credentials stored on that server. Installing MassPanel does not make the upstream project the controller of that data.

Operators must publish their own privacy notice, choose lawful retention periods, secure backups, restrict administrator access and provide processes for customer access or deletion requests where applicable. Mail, audit, firewall, web and support logs may contain IP addresses, identifiers and message metadata.

Optional external services, including Cloudflare and Let's Encrypt, receive the information required for the requested operation under their own terms and privacy policies. Cloudflare integration is disabled until the server owner supplies a token. MassPanel release packages contain no operator API token.

This document is operational guidance and is not legal advice.
