# Contributing to MassPanel

Contributions are accepted under the same `AGPL-3.0-or-later` licence as the project.

1. Discuss large or security-sensitive changes before implementation.
2. Keep each change focused.
3. Do not commit credentials, customer data, certificates, private keys, database dumps or machine-specific configuration.
4. Add or update tests for changed behaviour.
5. Run backend tests, the frontend build and release compliance checker.
6. Document user-visible and operational changes.
7. Record the origin and licence of every new dependency or copied file.

Bug reports should include the MassPanel version, Ubuntu version, expected and actual result, and sanitized logs. Security reports follow [SECURITY.md](SECURITY.md), not the public issue tracker.

By submitting a contribution, you certify that you have the right to submit it and agree that it may be distributed under `AGPL-3.0-or-later`.
