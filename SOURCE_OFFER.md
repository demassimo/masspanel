# Corresponding source

This MassPanel release contains the preferred source form for MassPanel and
the modifications it deploys. It also contains the exact upstream source
revisions retained for the installed Grommunio and Gromox components.

On an installed server, the source is available without charge from:

- `https://<panel-hostname>/masspanel-source`
- `https://<panel-hostname>/masspanel-corresponding-source.tar.gz`
- `https://<mail-hostname>/masspanel-source`
- `https://<mail-hostname>/masspanel-corresponding-source.tar.gz`
- `/usr/share/masspanel/source/masspanel-corresponding-source.tar.gz`

The source bundle includes build and installation scripts, the MassPanel
grommunio Web patch, licence notices and pinned upstream archives. No password,
licence purchase or MassPanel account is required to download it.

MassPanel is an independent project and is not an official grommunio product.
Questions about corresponding source may be sent to the support address shown
by the server owner in MassPanel.
