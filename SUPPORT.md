# Support

MassPanel public beta is provided without warranty or guaranteed response time.

- Use GitHub issues for reproducible, non-sensitive bugs and feature requests.
- Use GitHub discussions for setup questions when enabled.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
- Contact the operator of a hosted MassPanel server for customer account, website, DNS, billing, mailbox and data requests. The upstream project cannot access independently operated servers.

Before requesting help, record the MassPanel version, Ubuntu version, affected domain or component, exact error and relevant sanitized logs. Never post API tokens, passwords, cookies, private keys, mailbox contents or customer data.
